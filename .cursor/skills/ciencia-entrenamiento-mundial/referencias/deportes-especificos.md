# Protocolos por Deporte

Cubre los 6 deportes que `coach.py` lista como `deporte_principal`: gimnasio, crossfit, running, futbol, calistenia, natacion. Cada uno con principios, volumen, ejercicios clave, metricas y errores comunes.

## 1. Gimnasio (musculacion / fitness general)

### Principio
Hipertrofia y fuerza general usando barras, mancuernas, maquinas. Es el deporte mas estudiado.

### Estructura por nivel

**Principiante (3 dias FullBody A/B)**
```
Lunes A:  Sentadilla 3x5 | Banca 3x5 | Remo barra 3x8 | Plancha 3x30s
Miercoles B: Peso muerto 1x5 | Press militar 3x5 | Pull-up asistido 3x8 | Curl mancuerna 3x10
Viernes A:  Sentadilla 3x5 | Banca 3x5 | Remo 3x8 | Plancha 3x30s
```
Progresion: +2.5 kg/sesion upper, +5 kg/sesion lower hasta plateau.

**Intermedio (4-5 dias Upper/Lower o Push/Pull/Legs)**

PPL 6 dias (avanzado):
```
Lun Push:  Banca / Press militar / Press inclinado / Lateral / Triceps
Mar Pull:  Peso muerto / Dominada / Remo / Cara / Curl
Mie Legs:  Sentadilla / Hip thrust / Prensa / Isquios / Pantorrilla
Jue-Sab repite
```

UL 4 dias:
```
Lun Upper Heavy: Banca 4x6 / Remo 4x6 / Press militar 3x8 / Pull-up 3x6
Mar Lower Heavy: Sentadilla 4x6 / Peso muerto 3x4 / Lunge 3x10
Jue Upper Hyper: Banca incl 4x10 / Remo 4x10 / Lateral 4x12 / Curl + Triceps
Vie Lower Hyper: Front squat 4x10 / Isquios 4x10 / Prensa 3x12 / Pantorrilla 4x15
```

### Volumen / semana (intermedio)
| Musculo | Sets |
|---|---|
| Pecho | 12-16 |
| Espalda | 14-20 |
| Hombros | 12-18 |
| Cuadriceps | 10-16 |
| Isquios | 8-14 |
| Biceps | 10-16 |
| Triceps | 8-14 |

### Metricas de progreso
- 1RM (test cada 8-12 sem) en los 3 grandes
- Volumen semanal total (tonelaje)
- Pliegues / cintura cada 2-4 sem
- Fotos mensuales mismas condiciones

### Errores comunes
- Cambiar rutina cada 2 sem (no hay progresion medible)
- Solo aislados, evitando compuestos
- Saltarse piernas
- Ego lifting en banca y sentadilla con RIR negativo

## 2. CrossFit

### Principio
"Movimientos funcionales constantemente variados a alta intensidad". Combinacion de halterofilia, gimnastico y monoestructural (cardio).

### Estructura tipica de clase / sesion (~60 min)
```
1) Warm-up + mobility (10 min)
2) Skill / strength (15-20 min) - ej: snatch 5x1, o pull-up progression
3) WOD (10-20 min) - el "metabolic conditioning"
4) Cool-down + scoring (5 min)
```

### Distribucion semanal (CompTrain / Mayhem style)

| Dia | Foco |
|---|---|
| L | Olympic lifting + corta metcon |
| M | Strength (squat o dl) + long aerobic |
| X | Gymnastic skill + interval |
| J | Off o yoga / movilidad |
| V | Lift + chipper WOD |
| S | Long workout (>30 min) o competicion |
| D | Off activo |

### Movimientos clave
- Olimpicos: snatch, clean, jerk
- Powerlifting: back squat, front squat, deadlift, press
- Gymnastico: pull-up estricto y kipping, muscle-up, ring dip, handstand, walking, rope climb
- Mono: run, row, bike, ski erg, double under

### Metricas
- 1RM en snatch, clean&jerk, back squat, deadlift, press
- Benchmarks ("Fran" 21-15-9 thruster+pull-up, "Murph", "Grace", "Diane", "Helen")
- Hero WODs (no para principiantes)

### Errores comunes
- Hacer el WOD a tope todos los dias (sin programar intensidad)
- Tecnica oly con peso pesado sin coach
- Volumen alto de kipping sin base de pull-up estricto (lesion hombro)
- Ignorar mobility hombro/cadera/tobillo

## 3. Running

Base: ver [cardio-zonas.md](cardio-zonas.md) seccion VDOT y polarized.

### Principio
80/20 polarized: 80% del kilometraje en Z1-Z2 (facil), 20% en intervalos T/I/R.

### Estructura semanal recomendada (5K-10K, intermedio, 5 dias/sem)

| Dia | Sesion | Duracion |
|---|---|---|
| L | Easy run + drills | 30-45 min Z1-Z2 |
| M | Intervals (I) 5x800m @ I pace | 45 min total |
| X | Easy run | 30 min Z2 |
| J | Tempo (T) 20-30 min @ T pace | 45-50 min total |
| V | Off o cross-training | - |
| S | Long run | 60-90 min Z2 |
| D | Off o easy 30 min | - |

### Progresion de mileage
Regla del 10% (Daniels): no aumentar mas de 10% volumen semanal. Cada 4ta semana: deload -25%.

### Strength complementario (2x/sem corto)
- Sentadilla, peso muerto rumano, hip thrust, calf raise, core
- 30 min, mantener fuerza para reducir lesiones (Lauersen 2014 meta-analisis: -50% lesiones agudas, -33% overuse)

### Metricas
- 5K, 10K, half-marathon, marathon PRs
- VDOT (calculadora Daniels)
- Cadencia (objetivo 170-185 spm para mayoria)
- Cadence/zancada via app o reloj

### Errores comunes
- "Junk miles": todos los dias al mismo pace moderado (Z3) = ni recovery ni stimulus
- Saltarse long run
- Solo correr sin fuerza
- Subir mileage demasiado rapido (lesiones tibial, fascitis)
- Calzado sobre amortiguado siempre (perdida de propiocepcion)

## 4. Futbol

### Principio
Deporte intermitente: 8-12 km/partido con sprints repetidos, cambios de direccion, saltos. Combina aerobico, anaerobico, fuerza-velocidad, agilidad y tecnica.

### Estructura semanal en temporada (1 partido fin sem)

| Dia | Sesion |
|---|---|
| L | Recovery: 30-40 min Z2 + mobility |
| M | Strength gym (45-60 min) + tecnica |
| X | High intensity: sprints, intervalos, juegos reducidos |
| J | Tactica + tecnica + finalizacion |
| V | Activation: drills cortos, pase, set pieces. Bajo volumen |
| S/D | PARTIDO |

### Gym para futbolistas (Bompa, Bosch)

Foco en: fuerza posterior (hamstring, gluteo), cuadriceps, core, fuerza unilateral.

| Categoria | Ejercicios clave |
|---|---|
| Bilateral basico | Sentadilla, peso muerto |
| Unilateral | Bulgarian split squat, lunges, step-up |
| Posterior chain | Nordic hamstring, RDL, hip thrust, glute ham raise |
| Potencia | Power clean, jump squat, broad jump |
| Sprint mecanica | Sled push, hill sprints, A-skip, B-skip |
| Pliometria | Box jump, depth jump, lateral hop |

Volumen gym: 2-3 sesiones de 45 min en temporada; 3-4 de 60 min en pre-temporada.

### Conditioning especifico
- Sprints 10-40 m con descansos largos (1:6 ratio work:rest)
- Small-sided games (4v4, 5v5) con boundaries reducidos
- Yo-Yo Intermittent Recovery test (IR1, IR2) para medir progreso

### Prevencion de lesiones (foco hamstring + LCA)
- **Nordic hamstrings**: -51% incidencia lesiones isquios (van Dyk 2019 meta-analisis). 2x/sem, 3 sets x 5-10 reps.
- **FIFA 11+**: warm-up estandarizado, -30% lesiones (Soligard 2008).
- **Copenhagen adduction**: 2x/sem 3x10 lados, reduce lesiones aductor.

### Metricas
- Yo-Yo IR1, IR2 (capacidad repetir alta intensidad)
- 10m, 30m sprint
- Salto vertical (CMJ)
- 1RM relativa en sentadilla (>= 1.5x peso corporal)
- GPS data en partido (distancia, sprints, aceleraciones)

### Errores comunes
- Solo entrenar con la pelota, sin gym ni sprints estructurados
- Sin trabajo de hamstring (lesion #1 en futbol)
- Pretemporada solo correr larga distancia (es deporte intermitente, no maratoniano)

## 5. Calistenia

### Principio
Fuerza relativa al peso corporal usando dominadas, fondos, flexiones, planchas, palancas, banderas, anillas.

### Estructura semanal (intermedio 5 dias)

| Dia | Foco |
|---|---|
| L | Push: handstand press / dips / pseudo-PU progresion / lateral |
| M | Pull: dominada lastrada / front lever progresion / curl en anillas |
| X | Legs + Core: pistol squat / shrimp squat / nordic / hanging leg raise |
| J | Skill: handstand / planche / muscle-up / human flag |
| V | Push: hipertrofia con volumen (incline PU, dips, ring PU) |
| S | Pull: hipertrofia (rows en anillas, curl, ring pull-up) |
| D | Off |

### Progresiones clasicas

**Planche progresion**:
1. Plank
2. Tuck planche (10s hold)
3. Advanced tuck (20s)
4. Straddle planche (5s)
5. Full planche

**Front lever progresion**:
1. Tuck front lever
2. Advanced tuck
3. Straddle front lever
4. Full front lever

**Pistol squat progresion**:
1. Box squat unilateral
2. Pistol asistido en TRX
3. Pistol parcial
4. Pistol completa
5. Pistol con peso

**Muscle-up progresion**:
1. Pull-up explosivo "alto"
2. Negative muscle-up desde top
3. Banded muscle-up
4. Strict muscle-up
5. MU con peso

### Loading sin pesas
- Aumentar palanca (mas estatica = mas dura)
- Aumentar ROM (deficit push-ups)
- Reducir puntos de apoyo (one-arm)
- Tempo lento (3s eccentric, 1s pause)
- Lastre con cinturon dip (al final del techo de progresion)

### Metricas
- Reps strict pull-up, dip, push-up
- Hold time front lever, planche, handstand
- Reps pistol, one-arm push-up
- Skill ladder progresion

### Errores comunes
- Solo kipping (no fuerza real)
- Quemar hombros con MU sin progresion estricta
- Saltarse piernas (mito calistenico)
- Skill todos los dias sin recovery (codos, hombros)

## 6. Natacion

### Principio
Eficiencia tecnica > volumen. Sin tecnica solida, mas volumen = mas mal habito.

### Estructura sesion tipica (60-90 min)

```
1) Warm-up (10-15 min): 400-600 m suave mixto + drills
2) Tecnica/drills (10 min): un estilo focalizado, 4-6 drills x 50 m
3) Main set (30-45 min): segun foco del dia
4) Cool-down (10 min): 200-400 m suave
```

### Distribucion semanal (5 sesiones, swimmer intermedio)

| Dia | Foco principal | Volumen |
|---|---|---|
| L | Tecnica + Aerobico Z2 | 2-3 km |
| M | Intervalos threshold | 2.5-3.5 km |
| X | Drills + kick / pull | 2-2.5 km |
| J | Sprint / VO2 corto | 2-3 km |
| V | Off o gym |
| S | Long set (continuous) | 3-4 km |
| D | Open water o recovery | 1-2 km |

### Sets clasicos

**Threshold (CSS - Critical Swim Speed)**:
- 10x100m @ CSS pace con 10s descanso
- 8x200m @ CSS+2s con 20s descanso
- 5x400m @ CSS+5s con 30s descanso

CSS = (400 pace - 200 pace) / 200 = velocidad sostenible 30 min

**Sprint / VO2**:
- 8x50m all-out, 1:30 ciclo
- 6x100m all-out, 3:00 ciclo
- 4x200m 90% effort, 5:00 ciclo

**Drills**:
- Catch-up
- Fingertip drag
- 6-3-6 (rotacion + breathing)
- Single arm
- Closed fist
- Sculling
- Vertical kicking

### Strength complementario (1-2x/sem)
- Pull-up, lat pulldown, banded pull-throughs
- Trap-3 raise, YTW
- Plancha y anti-rotacion (palof)
- Rear delt fly
- Sentadilla, peso muerto (general)

### Metricas
- CSS, T-pace
- PR 50, 100, 200, 400, 1500 (4 estilos)
- Strokes per length (SPL) - eficiencia
- SWOLF = tiempo + SPL por largo

### Errores comunes
- Solo nadar sin gym (debilidad postural)
- Nada solo crol (atrofia musculatura espalda alta)
- Brazo flexionado, brazada corta (perdida de glide)
- No respirar bilateral (asimetria muscular)
- Patear con flexion de rodilla excesiva (drag)
